预设工具

大佬更新预设后，可以逐条挑选新版、自己改过的老版，或 AI 改好的正文，合成一份新的酒馆预设。

下载 Windows 工具（ZIP） 第一次用？看安装步骤

需要 Windows 和 Python 3.10 或更新版本。

第一次安装

  1. 下载并解压

    点页面上方的下载按钮。在 Windows 的「下载」文件夹里右键点击 ZIP，选「全部解压缩」，再点「提取」。

  2. 安装 Python

    如果电脑还没有 Python 3.10 或更新版本，到 Python 的 Windows 下载页下载安装。大部分电脑选 64-bit。安装界面若有「Add Python to PATH」，可以勾上。

  3. 打开工具

    在解压出来的文件夹里双击 启动.cmd。如果 Windows 隐藏文件后缀，文件名可能只显示「启动」。

怎么用

  1. 打开预设

    「新版本预设」选从大佬那里下载的 JSON，「自己改的老版本预设」选你自己在用的那份。只有新版时，勾选「只处理新版本」。

  2. 挑要分享的正文

    看过正文后点「标记 SFW」，再选导出哪一版。可以多选后点「批量导出所选 SFW」，一起保存成一个 JSON。把想删下来的私密内容留在工具里的便笺。

  3. 发给 AI，再放回来

    把导出的 JSON 和工具提示你复制的那段话发给 AI。收到结果后，点「放回 AI 改好的 JSON」。

  4. 检查并另存

    点「另存完整预设」，逐条选最终正文和开关。保存为一份新的 JSON，再到 SillyTavern 导入。

私密内容留在哪里？

这张网页只是下载和使用说明。程序在你的电脑上运行，便笺、完整预设和备份留在本机。要交给外部 AI 的是你核对过的交换 JSON。
