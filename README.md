# 预设版本管理器

Windows 本地工具。双击 `启动.cmd` 打开，需要 Python 3.10 或更新版本及 Tkinter。工具本身不上网。鼠标停在按钮上可以看约 10 秒的说明。把鼠标移到说明框上可以继续阅读，移开后说明会收起。

## 先打开文件

- **新版本预设**是你从大佬那里下载的新版本。点「找文件…」，在下载目录里找名字以 `.json` 结尾的那个。
- **自己改的老版本预设**是你上次自己改好、平时在用的那份。
- 手上只想处理大佬的新版，就勾「只处理新版本」，老版那一格留空。选好后点「打开预设」。

## 准备发给外部 AI

1. 在左边点一条，右边的「新版送审稿」和「老版送审稿」会显示这两份正文。
2. 如果只想删掉几句再送出去，把那些句子剪下，粘到这一条的「私密便笺」。切回送审稿，确认剩下的内容并点「保存这段修改」。送审稿和便笺会保存在本机，原来的 JSON 文件不受影响。切换条目、正常关闭窗口时，也会保存正在改的送审稿和便笺。
3. 在左边选条目，核对当下查看的版本，点「标记 SFW」记录可以分享的正文。它也支持多选。想逐条决定发哪个版本，就设置「仅新版」「仅旧版」「新旧都导出」或「不导出」。老版供参考，新版可在 AI 编辑后放回。选「新旧都导出」前，请分别标记两版正文。
4. 批量处理时，用「全选当前列表」或 Ctrl、Shift 多选，然后点「批量导出所选 SFW」。所有合格的选中条目会在同一个 JSON 里，写入的编号对应原条目，AI 调换顺序也能放回。每条已有的导出设置会优先采用，明确设为「不导出」的会跳过。没有逐条设置时，批量按钮只用当前查看的版本。「预览并导出」优先汇总已有设置；没有设置时，也可以直接预览选中的 SFW 条目。只处理新版时，还可以直接点「筛选已确认安全的新版并导出」。
5. 点「编辑 / 复制给 AI 的话」。框里的话可以自己改，点「一键复制」也会把它记到本机。去平常使用的 AI 聊天里粘贴这段话，附上刚导出的 JSON，一起发送。

## 把 AI 的修改放回来

1. 把 AI 回给你的 JSON 保存成一个文件，点「放回 AI 改好的 JSON」，选中它。如果关过窗口，请先用同样的文件和模式打开预设。
2. 红色的「手动删改过」提示你，这条原先的送审稿被手动改过。选中该条，打开「私密便笺」并复制要补回的句子。
3. 切到「AI 改完的正文」，把句子粘到合适的位置，再点「保存这段修改」。点「另存完整预设」会先打开保存前检查。左侧选条目，右侧决定用新版、自己的老版或 AI 改好的正文。可以对照各版本原文、编辑最终正文、复制同一张私密便笺。检查好后点「另存完整预设文件…」。
4. 「另存改好的补丁」只保存主窗口里编辑过的 AI 修改。保存前检查中的版本选择和最终正文用来生成完整预设文件。两种文件都可能含私密内容，请留在本机。

### 保存前检查里的开关

- 先点左边一条，在右边「发消息时要不要用这条？」里选开启或关闭。正文版本和发送开关可以分别设置。「用老版开关」把对应老版分组的状态带过来。每个排序分组可以单独设定，未手动改动的分组会沿用检查里的默认状态。
- 点「找以前用过我的老版的条目」，可以按条目编号从当前的老版里找回以前选过的条目。这是筛选，最终采用哪个版本还是由你决定。
- 导出成功后会自动弹出要和 JSON 一起发给 AI 的话，点「一键复制」即可。要改这段话，仍可从主界面的「编辑 / 复制给 AI 的话」进入。

## 怎样保存和回退

- 两份预设按条目 ID 对照。完整预设使用新版的顶层配置和现有顺序。没有手动选过的条目，优先用 AI 改好的正文，其次用新版。只在老版的条目默认不加入，手动选择「用我的老版」后，会带回它在老版里已有的排序记录。检查里的选择和编辑存于本机，再次打开同一组预设和同一轮 AI 正文可以继续。
- 「关键词」可搜当前查看版本的条目名、编号和送审稿正文。要只搜其中几条，先多选，再勾「只搜这批已选条目」。用空格隔开多个词，会查找同时含这些词的条目。
- 原文件备份在 `%LOCALAPPDATA%\PresetVersionManager\backups`。分类、送审稿、每条便笺、AI 提示词和导出批次记录在同级的 `reviews.sqlite3`，仅本地保存。便笺跟这次打开的预设组合及条目 ID 关联。要保留 AI 正文的后续本地改动，关闭程序前请另存完整预设或补丁。
- 需要回到改造前的程序时，关闭窗口，解压同级目录里的 `PresetManager-改造前备份-2026-11-26.zip` 到一个**新文件夹**，打开里面的 `PresetManager\启动.cmd`。这样当前程序也还留着。
- 想保留这次新增的开关和历史筛选、只退回美化前的界面时，解压同级目录里的 `PresetManager-UI-backup-2026-11-26.zip` 到新文件夹，再双击其中的启动文件。
- 支持原附件使用的 UTF-8 JSON 结构，需要有 `prompts`、`prompt_order` 和唯一的条目 `identifier`。压缩包需先解开再找 JSON。程序不会执行里面的脚本。原有排序、扩展和未知配置由新版透传。
- 定位程序问题时，可在此目录运行 `py -3 -m unittest -v`。把 `PRESET_TEST_SAMPLE` 指向原附件可加跑真实文件的往返测试。
