# 快速缝合预设工具

这是一个给 **SillyTavern（酒馆）预设**用的 Windows 小工具。大佬更新预设后，你可以从新版、自己改过的老版和 AI 改好的正文里，**逐条挑出想留的内容**，拼成一份新的预设。原来的文件会留在原处。

工具本身不上网。你可以在发给外部 AI 前挑选正文，把私密片段暂存在本机，等 AI 改完后再补回去。

## 第一次用，从这里开始

1. **下载工具。** 在这个 GitHub 页面上方点绿色的 **Code**，再点 **Download ZIP**。
2. **把 ZIP 解开。** 打开 Windows 的「下载」文件夹，右键点刚下载的压缩包，选「全部解压缩」，再点「提取」。打开解压出来的文件夹，找到 `启动.cmd`。
3. **安装 Python。** 电脑已经装好 Python 3.10 或更高版本，可以跳过这步。没有的话，到 [Python 的 Windows 下载页](https://www.python.org/downloads/windows/) 选一个稳定版的 Windows 安装程序。大部分电脑用 **64-bit**。打开安装程序，勾上 **Add Python to PATH**（如果界面有这个选项），再点 **Install Now**。让安装程序一并安装 Python Launcher 和 Tkinter。
4. **双击 `启动.cmd`。** 如果 Windows 隐藏了后缀，你看到的名字可能只是「启动」。打开后，把鼠标停在按钮上可以看说明。移到说明框里可以继续读，移开就会收起。

如果双击后提示找不到 `py`，先确认 Python 已经安装，再关掉提示重新打开。如果仍然有问题，可以重新运行安装程序，检查有没有安装 Python Launcher。

## 第一次改预设，照着做

### 1. 找到新版和你自己的老版

- **新版本预设**：从大佬那里下载下来的新版文件。
- **自己改的老版本预设**：你上次亲手改好、自己在酒馆里用的那份。
- 点对应的「找文件…」，选文件名以 `.json` 结尾的文件，再点「打开预设」。预设如果也在 ZIP 里，先解压。
- 只想改新版时，勾上「只处理新版本」，老版可以留空。

### 2. 挑出可以发给 AI 的正文

1. 在左边选条目，右边看正文。想找关键词，用列表上方的「关键词」。想一起选几条，可以按住 **Ctrl** 点条目，也可以点「全选当前列表」。
2. 如果正文里有几句不想发，剪下来放到这一条的「私密便笺」，再保存右边的送审稿。便笺和删改后的送审稿会留在电脑里，下次打开同一组预设还能找到。原来的文件不会被改写。
3. 核对可分享的正文，点 **「标记 SFW」**。这表示你同意把这份正文分享出去。「标记 NSFW」会把对应版本从导出清单里移走。
4. 要分别挑版本，就给条目点「仅新版」「仅旧版」「新旧都导出」或「不导出」。想一次发一批，就多选后点 **「批量导出所选 SFW」**。核对预览，再把生成的 JSON 保存到一个找得到的位置，比如桌面。一个 JSON 可以装多条，工具会用编号记住每条的位置。
5. 导出成功后，会弹出要发给 AI 的话。点 **「一键复制」**，到你平常用的 AI 聊天里按 **Ctrl+V**，把刚导出的 JSON 当附件一起发。如果想改这段话，从主界面点「编辑 / 复制给 AI 的话」。

只处理新版时，「筛选已确认安全的新版并导出」会找出你以前确认过、正文也没变的条目。第一次用时，需要先自己审核并标记 SFW。

### 3. 把 AI 改好的内容放回去

1. 把 AI 返回的 JSON 保存为文件。点 **「放回 AI 改好的 JSON」**，选中它。如果你关过工具，先用原来的文件和模式重新打开。
2. 红色的「手动删改过」提醒你之前改过送审稿。要补回某句话，去这条的「私密便笺」复制，再粘进「AI 改完的正文」并保存。
3. 点 **「另存完整预设」**。这会先打开检查窗口，你可以逐条选「用新版」「用我的老版」或「用 AI 改好的」，也可以直接编辑最终正文。之前经常需要保留的条目，可以用「找以前用过我的老版的条目」来找。
4. 想决定发送时是否用这条，在右侧设置 **开启** 或 **关闭**。也可以点「用老版开关」，沿用对应老版排序分组的状态。正文版本和开关是两件事，可以分别选。
5. 最后点 **「另存完整预设文件…」**，新建一份 JSON。回到 SillyTavern，用平时导入预设的地方导入这一份。

## 常见问题

- **默认会用哪份正文？** 有 AI 修改的条目默认用 AI 版，其余用新版。只在老版有的条目，可以在检查窗口手动加入。
- **AI 调换了排序，还能放回去吗？** 可以。只要它保留工具给的批次和条目编号，工具会按编号找到原条目。
- **哪些文件可以发给外部 AI？** 只发在「导出给 AI」区域预览并保存的交换文件。完整预设、自己补回文字后另存的补丁、便笺和本机备份可能含私密内容，请留在本机。
- **我的备份和便笺放在哪？** 在 Windows 文件资源管理器的地址栏粘贴 `%LOCALAPPDATA%\PresetVersionManager`，按回车。「backups」放原件备份，`reviews.sqlite3` 放便笺、分类和检查记录。
- **所有 JSON 都能打开吗？** 支持 SillyTavern 这类含 `prompts` 和 `prompt_order` 的预设，每个条目需要有自己的 `identifier`。这个工具不会运行预设里的脚本或扩展。

## 给想检查代码的人

只使用 Python 标准库和 Tkinter。在程序目录运行 `py -3 -m unittest -v` 跑测试。把 `PRESET_TEST_SAMPLE` 指向对应原始附件，可额外跑真实预设往返测试。
